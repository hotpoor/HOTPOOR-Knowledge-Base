# HOTPOOR Knowledge Base

记录日常技术问题的排查与解决方法，把一次修复变成可以复用的知识。

内容以中文为主，按主题归档。每篇笔记尽量说明现象、证据、操作方法、验证方式及撤销方法，区分已确认的结果与尚待验证的推断。

## 编写约定

- 先记录现象与证据，再选择对应修复，避免一次执行所有命令。
- 说明命令的适用条件、权限要求以及可能影响。
- 区分“命令执行成功”“网络连接恢复”和“用户界面正常”。
- 不提交密码、令牌、私人主机地址、账户信息或未经脱敏的日志。
